# Wreckbox 1.8 для Android 2.3.6

Нативный порт на **Android 2.3.6 / API 10**. Это не WebView-обёртка: симуляция и программный renderer работают через общий Java Core с J2ME-портом. Официальный APK 1.8 требует API 22 и остаётся источником для сверки, а не основой этого пакета.

## Готовый APK

`release/Wreckbox-1.8-Android2.3.6.apk`

- пакет: `ru.vanc67.wreckbox`, версия `1.8` (`versionCode=18`);
- `minSdkVersion=10`, `targetSdkVersion=10`;
- один `classes.dex` формата **035**, без нативных библиотек и multidex;
- разрешений, включая INTERNET, нет;
- подпись JAR/v1 **SHA256withRSA / SHA-256**, понятная Gingerbread;
- включён локальный debug-keystore (`wreckbox` / alias `wreckbox`) для воспроизводимой пересборки и обновления без смены сертификата. Это не сертификат релиза в Google Play.

На телефоне разрешите установку из неизвестных источников, скопируйте APK на карту памяти и откройте его. При наличии ADB: `adb install Wreckbox-1.8-Android2.3.6.apk`.

## Что перенесено

- **8 карт**, **27 инструментов**, 21 материал, 103 prop-типа и 13 зданий;
- NORMAL / FAST / DETAILED physics, опоры, перегруз, разломы и shaped/material debris;
- жидкости, огонь, электросеть, жители и 11-точечный ragdoll;
- bomb / nuke / bomber, радиация, shelters, NPP SCRAM/release/evacuation;
- пожарные, полиция, скорая и остальные текущие service-механики;
- 12 day/night RGB/RGBA texture-атласов и **54 AMR** из проверенного resource-set;
- меню карт и инструментов без прогресса, покупок и открываемого контента.

Core и ресурсы берутся напрямую из `../wreckbox-j2me/src/main`; механика не дублируется отдельным Android-форком. Android-модуль заменяет только LCDUI, ресурсы, настройки, звук, ввод и lifecycle.

## Управление

### Сенсорный экран

- касание мира — применить инструмент; ведение и отпускание — непрерывное действие / бросок;
- верхняя панель слева — главное меню; справа — управление симуляцией и команда детонации;
- нижние левый/правый края — предыдущий/следующий инструмент;
- название инструмента внизу — список всех 27; нижняя строка силы — изменить силу или вариант;
- вертикальное ведение прокручивает карты, инструменты и текстовые страницы;
- инструмент «Камера»: ведение двигает вид, щипок двумя пальцами меняет масштаб;
- Back — назад; из главного меню — выход.

### Аппаратные клавиши

DPAD — курсор/меню, Center/Enter/Space — действие, `1/3` — инструмент, `7/9` — сила/вариант, `0` — гравитация, `#` — детонация, `*` — панель управления, `P` — пауза, Menu — главное меню.

При сворачивании игровой поток и звук останавливаются, при возвращении поток запускается заново. Настройки и выбранные карта/инструмент сохраняются через `SharedPreferences`.

## Проверки

`build.sh` после сборки проверяет:

1. API-10 badging и launcher Activity;
2. DEX 035, лимит method references, отсутствие WebView/native/multidex;
3. побайтовое совпадение всех 8 WBMP (+ map index), 12 PNG и 54 AMR с исходным resource-set;
4. хранение AMR без сжатия для `AssetManager.openFd` / `SoundPool`;
5. ZIP CRC и настоящую проверку подписи через `jarsigner -verify`;
6. SHA-256 готового файла в `release/SHA256SUMS`.

Общие JVM-регрессии: **788/788 PASS** — Core 670, Platform 62, Canvas 56; LowHeap PASS при `-Xmx2560k`.

**Ограничение проверки:** статическая проверка APK и desktop JVM не являются запуском на физическом Android 2.3.6. Полная побайтовая/игровая parity с оригиналом 1.8, включая все тонкости service crew/hospital/return и звука на конкретном телефоне, не заявляется.

## Пересборка

Нужны JDK, Python 3, AAPT2, API-10 `android.jar` и desktop D8/R8 JAR с точкой входа `com.android.tools.r8.D8`.

```sh
export ANDROID_JAR=/path/to/platforms/android-10/android.jar
export AAPT2=/path/to/aapt2
export D8_JAR=/path/to/r8.jar
# При необходимости также задайте JAVAC/JAVA/JAR/JARSIGNER/KEYTOOL.
./wreckbox-android/build.sh
```

`D8_JAVA_FLAGS` можно использовать для нестандартной локальной D8-обёртки. Генерируемый `build/` не входит в Git. Иконка воспроизводится командой `node wreckbox-android/tools/generate_icon.js`.
