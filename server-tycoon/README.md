# Server Tycoon: Datacenter Sandbox

Мобильная offline-игра «Сисадмин: Песочница». Готовый установочный пакет: **`ServerTycoon.apk`**.

## Внутри

- четыре мобильные вкладки: ферма, Авито, инвентарь, статистика;
- изометрические inline-SVG и Canvas-графики без внешних ассетов;
- генератор 5–10 лотов, торг с шансом испортить сделку, пять состояний техники;
- 2D-конструктор с touch/mouse drag-and-drop и режимом «деталь → слот»;
- сокеты LGA775/LGA2011/LGA2011-3, DDR2/DDR3/DDR4, SATA, TDP кулера и расчёт мощности БП;
- записываемые USB-образы Debian 12, Windows Server, TrueNAS SCALE и Proxmox VE;
- мини-игра установки ОС со случайными ошибками и продолжением после сбоя;
- Jellyfin, File Browser, BOINC и Local AI с разным расходом CPU/RAM и доходом;
- нагрев, троттлинг выше 85 °C, BSOD на 95 °C, OOM-зависания, шум и штрафы;
- почасовой доход, стоимость электричества, аренда, долг провайдеру и отключение света;
- улучшение помещения, помощь мамы и sandbox-пополнение баланса;
- автоматические локальные сохранения.

## Android

- package: `ru.vanc67.servertycoon`;
- minSdk 23 (Android 6.0), targetSdk 35, портретная ориентация;
- нативная WebView-оболочка без Capacitor/Cordova runtime;
- разрешение `android.permission.INTERNET` отсутствует, весь контент находится в `assets/www`;
- APK подписан debug-ключом RSA/SHA-256, включены схемы подписи v1/v2/v3.

Сборка выполняется напрямую через AAPT2, ECJ, D8 и APK Signer скриптом `build_apk.py`. Путь к локальному toolchain передаётся переменной окружения `ANDROID_BUILD_TOOLS`.

## Проверки

`tests/logic.test.cjs` покрывает совместимость DDR, мощность БП, установку ОС/BOINC, доход, перегрев, OOM, генератор лотов, торг, долги и ускоренный день. Дополнительно проведены DOM smoke test полного пользовательского сценария и визуальный Chromium-тест на мобильном viewport 412×915.
