# Готовая сборка

Для Sony Ericsson K510i скопируйте в одну папку:

- `RetroDestructionLab.jar`
- `RetroDestructionLab.jad`

Откройте JAD для установки либо JAR, если прошивка поддерживает прямую установку. Не переименовывайте файлы — размер и URL в JAD соответствуют этой сборке.

Профиль: **MIDP 2.0 / CLDC 1.1, 128×160**. Все материалы и сцены доступны сразу. Полное управление и сборка из исходников описаны в `../README.md`.
