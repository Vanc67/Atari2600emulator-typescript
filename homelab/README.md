# HomeLab: От Авито до Дата-Центра

Полноценная браузерная игра по концепту «домашний сервер своими руками»: покупаешь б/у железо на барахолке, собираешь
сервер руками, ставишь Linux или Windows Server, работаешь в терминале, берёшь заказы у клиентов, обжимаешь патч-корды,
отбиваешь DDoS и постепенно переезжаешь из комнаты в гараж, а потом — в настоящий ЦОД.

Никаких кнопок «улучшить процессор»: всё делается через покупку деталей, сборку, конфигурацию и обслуживание.

## Запуск

```sh
cd homelab
npm install
npm run dev        # http://localhost:3100
```

```sh
npm run build      # прод-сборка (tsc + vite) в dist/
npm run preview    # проверить прод-сборку
npm run test:all   # смоук-тесты логики, баланс-симуляция 90 дней, рендер всех экранов
```

Прогресс автоматически сохраняется в `localStorage`. Кнопка ⟲ в шапке начинает игру заново.

## Что внутри

### Три этапа

| Этап | Локация | Чем занимаешься |
| --- | --- | --- |
| 1. Комнатный хакер | Комната | Старый родительский ПК, смартфон на антресолях, первые SMB/Jellyfin/веб-заказы |
| 2. Гаражный сисадмин | Гараж | Шкаф 12U, стоечный сервер, RAID, кабели Cisco, DDoS-атаки, турбины |
| 3. Владелец ЦОД | ЦОД | Блейд-шасси, СХД, 10G-магистраль, BGP, генератор, сотрудники |

### Барахолка и торг

- Каждый день появляются новые объявления: платформы, CPU, DDR3/ECC-память, диски, кулеры, сетевые карты.
- У деталей есть **скрытые дефекты** (bad-секторы, погнутые ножки, гудящий вентилятор, ошибки памяти, умирающий БП...).
- Можно **проверить товар** (150 ₽), **спросить продавца**, **надавить** (работает от навыка железа) или **предложить цену** —
  и получить скидку, если повезёт. Слишком много попыток — продавец обидится и поднимет цену.
- Доставка приходит на следующий день, так что планировать надо заранее.

### Сборка и обслуживание

- Сокеты, слоты памяти (ECC в десктоп не встанет и наоборот), отсеки дисков, кулер, сетевая карта.
- Пыль, термопаста, перегрев, аварии, диагностика SMART/memtest, ремонт дефектов.
- RAID-1 и RAID-5 с риском развала массива при низком навыке и защитой от потери данных.
- iLO на стоечных серверах: удалённая перезагрузка после зависания.

### ОС и терминал

- **Ubuntu Server** — настоящая консоль: `apt update`, `apt install samba`, `systemctl status smbd`, `ufw enable`,
  `free -h`, `df -h`, `lsblk`, `smartctl`, `sensors`, `top`, `ip a`, `docker compose up -d`, `neofetch`, `vtysh` (BGP)
  и ещё десяток команд. Учебно, но влияет на игру по-настоящему.
- **Windows Server 2016** — графический интерфейс: Desktop Experience, служба звука, диспетчер задач, управление дисками,
  расшаривание папок. Лицензия стоит денег.
- **Android 2.3** на старом смартфоне — tiny-нейросеть и веб-морда.

### Экономика и жизнь

- Клиенты платят аванс и подневную ставку, но требуют сервис, память, ядра, диски, firewall и аптайм. Один день простоя —
  предупреждение, второй — неустойка и репутация вниз.
- Электричество по счётчику каждый день, аренда ЦОДа, зарплата эникеям, солярка для генератора.
- Шум бесит семью и соседей: шумоизоляция, тихие кулеры, шкаф, переезд меняют ситуацию.
- Случайные события с выборами: мама стучит в дверь, диск сыпется, кот залил чай, сосед жалуется, клиент просит скидку,
  провайдер отключил интернет, электрик предлагает «оптимизировать» счётчик, кондиционер в гермозоне сдох и т.д.

### Мини-игры

- **Обжим патч-корда** по схеме T568B — ошибки запоминаются, идеальный обжим даёт больше кабелей и навыка.
- **Отражение DDoS** — отфильтровать SYN-флуд, не убив легитимный трафик, пока не вышло время.

Победа: этап 3, репутация 90+, 25 выполненных контрактов. Проигрыш: долги ниже −8 000 ₽.

## Структура

```
src/game/types.ts      типы состояния, действий, деталей, контрактов
src/game/data.ts       контент: детали, сервисы, контракты, апгрейды, флавы
src/game/rules.ts      производные величины: ядра/память/диски/шум/температура/firewall, проверка контрактов
src/game/market.ts     генерация лотов и машин, случайности
src/game/commands.ts   терминал Linux (чистая функция, меняет копию машины)
src/game/events.ts     24 события с выборами
src/game/guidance.ts   подсказки «что делать дальше»
src/game/game.ts       редьюсер: все действия и ночной цикл (экономика, аварии, контракты)
src/components/*       HUD, комната, барахолка, сборка/ОС, заказы, путь, модалки, мини-игры
public/art/*.png       фоны комнаты, гаража и ЦОДа
tests/smoke.ts         логика: команды, покупки, контракты, события, 90 дней
tests/balance.ts       симуляция игрока на 90 дней (проверка достижимости прогресса)
tests/render.tsx       серверный рендер всех экранов (ловит runtime-ошибки UI)
```
